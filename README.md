# animal-labor-server
基于SpringBoot3+Vue3前后端分离的动物实验中心管理系统（源码+文档），系统包含管理员、仓管员、研究员角色，功能如下： 管理员：首页统计；仓管人员；研究人员；动物管理（动物分类、动物管理、健康记录、动物申请）；物资管理（仓库管理、物资管理、物资采购、物资申请）；实验管理（实验场所、实验信息）；投诉管理；留言管理；公告管理；修改个人资料；修改密码。 仓管员：动物管理（动物管理、健康记录登记、动物申请审核）；物资管理（仓库查看、物资查看、物资采购、物资申请审核）；投诉管理；留言管理；公告查看；修改个人资料；修改密码。 研究员：动物管理（动物查看、申请、取消、归还）；物资管理（物资查看、申请、物资申请取消）；实验场所（实验场所、实验信息）；投诉管理；留言管理；公告管理等。
