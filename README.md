## 【原创】SpringBoot3+Vue3前后端分离的动物实验中心管理系统（源码+文档）

## 系统介绍

基于SpringBoot3+Vue3前后端分离的动物实验中心管理系统（源码+文档），系统包含管理员、仓管员、研究员角色，功能如下：
- 管理员：首页统计（动物饼状图统计、7天实验统计）；仓管人员；研究人员；动物管理（动物分类、动物管理、健康记录、动物申请）；物资管理（仓库管理、物资管理、物资采购、物资申请）；实验管理（实验场所、实验信息）；投诉管理；留言管理；公告管理；修改个人资料；修改密码。
- 仓管员：动物管理（动物管理、健康记录登记、动物申请审核）；物资管理（仓库查看、物资查看、物资采购、物资申请审核）；投诉管理；留言管理；公告查看；修改个人资料；修改密码。
- 研究员：动物管理（动物查看、申请、取消、归还）；物资管理（物资查看、申请、物资申请取消）；实验场所（实验场所、实验信息）；投诉管理；留言管理；公告管理；个人信息修改；密码修改。
系统界面美观大方，功能丰富，使用了SpringBoot3、Vue3、Element-Plus、Echarts等技术栈。

项目由本人原创开发，经过多次测试，项目运行无问题，请放心使用，作者QQ：1344127185。

## 使用技术

服务器端技术栈：

- Springboot3
- SpringMvc
- Mybatis
- MySQL

前端技术栈：

- vue3
- element-plus
- axios
- echarts

## 环境介绍

- IDEA集成环境
- JDK17+
- MySQL8.0+

可提供所有运行软件、远程安装、技术指导。
